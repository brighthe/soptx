# 制造解前向收敛阶验证（论文 5.1 节）

## 1. 研究对象

在单位正方形上用混合边界正弦制造解检验 Hu--Zhang 混合有限元的收敛阶：高阶原生格式 $k = 3, 4$（表 5.1）与低阶跳量稳定化格式 $k = 1, 2$（表 5.2），各五级均匀加密网格，报告位移 $L^2$、应力 $L^2$ 与应力 $H(\mathrm{div})$ 三项误差及观测阶。

模型为 [`MixedBoundarySinusoidalElasticity2D`](../../docs/problems/manufactured/mixed-boundary-sinusoidal-elasticity-2d.md)：$\Gamma_D = \{x = 0\} \cup \{y = 0\}$ 上齐次位移，$\Gamma_N = \{x = 1\} \cup \{y = 1\}$ 上施加精确应力的法向迹，体力由精确解反推。

## 2. 实验设置

实验脚本为 [`run_manufactured.py`](run_manufactured.py)，一次运行跑完全部阶次：

```bash
python experiments/paper_topopt_huzhang/run_manufactured.py                 # 论文口径 (不松弛)
python experiments/paper_topopt_huzhang/run_manufactured.py --relaxation    # 开启角点松弛的对照
```

### 2.1 模型参数

| 参数 | 数值或设置 |
|---|---|
| 区域 | $[0, 1]^2$，平面应变，固定于模型类 |
| 材料 | $\lambda = 1$，$\mu = 0.5$：`LAME_LAMBDA = 1.0`，`SHEAR_MODULUS = 0.5` |

### 2.2 分析参数

| 参数 | 数值或设置 |
|---|---|
| 网格 | $n_x \times n_x$ 棋盘式交替对角线三角形网格，$n_x = 4, 8, 16, 32, 64$，$h = \sqrt{2}/n_x$：`TriangleMesh.from_checkerboard_box`，`SUBDIVISIONS = (4, 8, 16, 32, 64)` |
| 阶次 | 应力空间次数 $k \in \{1, 2, 3, 4\}$，位移空间次数 $k - 1$：`--degree`，缺省全部 |
| 稳定化 | $k = 1, 2$ 用矩阵型跳量稳定化，$\alpha = \mu / L_0^2$，$L_0 = 1$；$k = 3, 4$ 原生鞍点格式：`STABILIZATION = {1: "matrix_jump", 2: "matrix_jump", 3: "none", 4: "none"}` |
| 数值积分 | $2k + 2$ 阶：`integration_order=2 * degree + 2` |
| 角点松弛 | 论文口径不松弛：`USE_RELAXATION = False`。唯一的牵引–牵引角点 $(1, 1)$ 处两边牵引来自同一光滑对称应力，满足 Hu 与 Ma（2021）4.1 节的一致性条件 $(n_-^\mathsf{T} g\vert_{e^+})(x_c) = (n_+^\mathsf{T} g\vert_{e^-})(x_c)$，常规节点插值良定义，无需松弛。可用 `--relaxation` 开启，此时网格自动检出的四个几何角点全部松弛，含三个邻接位移边的角点，超出 Hu 与 Ma 只处理牵引不一致角点的范围（见 3.1 节） |
| 线性求解器 | MUMPS 直接法：`SOLVER = "mumps"` |
| 误差与观测阶 | $\|u - u_h\|_0$、$\|\sigma - \sigma_h\|_0$、$\|\sigma - \sigma_h\|_{H(\mathrm{div})} = (\|\sigma - \sigma_h\|_0^2 + \|\nabla\cdot(\sigma - \sigma_h)\|_0^2)^{1/2}$，按 $2k + 2$ 阶积分计算；观测阶 $\log_2(e_h / e_{h/2})$，首级记空 |

## 3. 结果

入库结果在 `results/manufactured-convergence/` 下分两组，均于 2026-10-15 用同一代码（`git 0218413`）算出：

- `relaxation-off/`：论文口径（不松弛），含数据 `manufactured_convergence.json` 与表格 `table5_1.md`（$k = 3, 4$）、`table5_2.md`（$k = 1, 2$）；两张表经 `sync_results.py --paper-tables` 拷到 `results/tables/`，即论文表 5.1 与表 5.2；
- `relaxation-on/`：开松弛的对照，文件同上，不进论文表。

两份数据的溯源戳记均为 `git_dirty: true`：运行时工作区有与本算例无关的未提交改动（`cantilever_stress.md`、`run_cantilever_stress.py`）。开松弛结果与此前入库的 `30d1bd9` 版逐格对照，误差最大相对差 $4.3\times10^{-6}$，观测阶无差别。

观测阶：$k = 2, 3, 4$ 时位移 $L^2$ 与应力 $H(\mathrm{div})$ 趋于 $k$，应力 $L^2$ 趋于 $k + 1$；$k = 1$ 时位移与 $H(\mathrm{div})$ 为 1，应力 $L^2$ 约 1.5。

## 4. 实验结论

- 不松弛（论文口径）时，$k = 3, 4$ 原生格式三项误差均为最优观测阶（位移与 $H(\mathrm{div})$ 为 $k$，应力 $L^2$ 为 $k + 1$）。$k = 1, 2$ 跳量稳定化格式的理论估计为 $\|\sigma - \sigma_h\|_{H(\mathrm{div})} + \|u - u_h\|_0 \lesssim h^k$（Chen 等 2017，定理 3.3），不单独给出应力 $L^2$ 估计：$k = 2$ 位移与 $H(\mathrm{div})$ 为 2 阶，应力 $L^2$ 为 3 阶；$k = 1$ 位移与 $H(\mathrm{div})$ 为 1 阶，应力 $L^2$ 约 1.5 阶，高于理论保证的 1 阶，未达 $k + 1$。
- 开启角点松弛不改变任何阶次的收敛阶：$k \ge 2$ 时三项误差与不松弛相差不超过 $0.13\%$；$k = 1$ 粗网格相差可达约 $10\%$（$n_x = 4$ 位移，不松弛的误差大 $9.8\%$），随加密减小，$n_x \ge 16$ 后不超过 $2\%$，且方向不一：松弛后位移误差略小，应力 $L^2$ 误差略大。这与 Hu 与 Ma 的判据一致：角点牵引数据一致时松弛不是必需的，故论文口径不松弛。
