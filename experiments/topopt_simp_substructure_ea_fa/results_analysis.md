# 子结构有限元 EA 与 FA 拓扑优化结果对照

硬件：AMD Ryzen 9 9950X（16 核 32 线程），运行内存 45 GiB（WSL2 上限 48 GB）；NVIDIA GeForce RTX 5070 Ti，显存 16 GB。

软件：Ubuntu 24.04（WSL2），`ihpcm` 环境，Python 3.12.13；NumPy 2.5.3（conda-forge，链接 BLIS 2.0 与 netlib LAPACK），SciPy 1.18.1（内置 scipy-openblas 0.3.31），PyTorch 2.11.0（CUDA 12.8）；PyMUMPS 0.4.0，链接 MUMPS 5.8.2（BLIS 2.0、netlib LAPACK、Open MPI 5.0.11、ScaLAPACK 2.2.0）；pyevtk 1.7.0。

本文分别对照同一接口空间内的 EA 与 FA。`full_trace` 的 EA 采用共享参考细单元刚度与隐式 Schur 作用；`linear_corner` 的 EA 通过共享参考细单元刚度构造并保存局部角点 Schur 补。两种 EA 都避免全局接口装配，但局部矩阵的存储与作用方式不同。各块数值结果均待填，接口之间的方法误差参见 `../topopt_simp_substructure_fa/substructure_vs_fem_topopt_results.md`。

## 1. full_trace：EA（隐式 Schur）与 FA

### 1.1 研究对象

对照子结构有限元 EA 与 FA 两种刚度算子实现，在 CPU 上对 Huang2023 三维 MBB 梁（$390\times65\times65$，$1647750$ 个单元，$5109588$ 个全场自由度）的完整优化结果。两侧固定采用 `full_trace` 与精确静态缩聚；EA 侧采用共享参考细单元刚度与隐式 Schur 作用，FA 侧显式形成局部 Schur 补并装配全局接口 CSR。当前为待实现、待运行的实验框架。

| | EA | FA |
|---|---|---|
| 细单元刚度 | 共享一份参考细单元刚度 $K^0$，按材料系数 $s_e$ 缩放，实现局部算子作用 | 复用参考细单元刚度，按材料系数缩放后装配子结构局部矩阵 |
| 子结构局部存储 | 装配内部矩阵 $K_{ii}^j$ 并保存其 Cholesky 分解，不形成完整局部刚度与局部 Schur 补 | 分批形成完整局部刚度，并显式计算局部 Schur 补 $S_j$ |
| 全局接口算子 | 不装配全局接口矩阵，通过隐式 Schur 作用实现 | 将各子结构的局部 Schur 补散加成全局接口 CSR 矩阵 $S$ |
| 矩阵向量积 | 提取子结构接口向量，通过细单元 EA 作用与内部回代计算局部 Schur 作用，再散加到全局接口向量 | 直接通过全局接口 CSR 矩阵计算 $Sx$ |

第 $j$ 个子结构的内部与边界自由度分别记为 $i$、$b$。EA 每次局部 Schur 作用先求解 $K_{ii}^jv_i=-K_{ib}^jx_b$，再计算 $S_jx_b=K_{bb}^jx_b+K_{bi}^jv_i$；其中各刚度分块的作用由共享参考细单元 EA 实现，无需保存 $K_{bb}^j$、$K_{ib}^j$ 或 $K_{bi}^j$。内部分解在同一轮的接口迭代与位移恢复中复用，随密度更新重新建立，不显式求逆。

这里的 matrix-free 指接口算子，内部矩阵仍显式装配和分解。共享的是细单元参考刚度，不是各子结构的 Schur 补；各子结构内部密度通常不同，需分别建立内部分解。本对照同时改变局部 Schur 补形成方式与全局接口装配方式。

材料、载荷、支承（`end_corners`，即 `FullMBBBeamPoint3d`）、子结构划分、边界条件消元、MGCG 求解器与容差、热启动、过滤、OC 与停止条件两侧保持一致；MG 预条件策略、参数与粗层求解器也采用相同设置，实际实现差异在运行后注明。预条件子或粗层中的显式矩阵，其装配、存储与求解成本均计入统计。

## 2. linear_corner：EA（局部角点 Schur 补）与 FA

### 2.1 研究对象

对照子结构有限元 EA 与 FA 两种刚度算子实现，在 CPU 上对 Huang2023 三维 MBB 梁（$390\times65\times65$，$1647750$ 个单元，$5109588$ 个全场自由度）的完整优化结果。两侧固定采用 `linear_corner`，通过角点线性插值描述子结构边界位移，内部自由度采用精确消元；EA 侧采用共享参考细单元刚度构造并保存局部角点 Schur 补，FA 侧将局部角点 Schur 补装配成全局角点 CSR。当前为待实现、待运行的实验框架。

| | EA | FA |
|---|---|---|
| 细单元刚度 | 共享一份参考细单元刚度 $K^0$，按材料系数 $s_e$ 缩放，实现局部算子作用 | 复用参考细单元刚度，按材料系数缩放后装配子结构局部矩阵 |
| 子结构局部存储 | 装配并分解内部矩阵，直接形成并保存局部角点 Schur 补 $S_{C,j}$，不形成完整边界 Schur 补 | 分批形成完整局部刚度与边界 Schur 补，再投影为局部角点 Schur 补 |
| 全局接口算子 | 不装配全局角点矩阵，保存各子结构的局部角点 Schur 补 | 将局部角点 Schur 补散加成全局角点 CSR 矩阵 $S_C$ |
| 矩阵向量积 | 提取子结构角点向量，以保存的 $S_{C,j}$ 作用后散加到全局角点向量，接口 matvec 不做内部回代 | 直接通过全局角点 CSR 矩阵计算 $S_Cx$ |

令 $L_j$ 将角点位移插值到子结构边界。EA 求解 $K_{ii}^jT_{C,j}=-K_{ib}^jL_j$，直接形成 $S_{C,j}=L_j^{\mathsf T}(K_{bb}^jL_j+K_{bi}^jT_{C,j})$，其中刚度分块的作用由共享参考细单元 EA 实现。三维八角点各有三个位移自由度，每个 $S_{C,j}$ 为 $24\times24$，内部求解只有 24 个右端，无需形成完整边界 Schur 补。恢复可保存 $T_{C,j}$，或重新求解内部系统，实际选择及成本在运行后注明。

这里的 EA 在角点层保存局部矩阵，与 `full_trace` 每次 matvec 隐式计算 Schur 作用不同。两者都不装配全局接口矩阵，也都可结合共享参考细单元 EA；各子结构密度不同，局部角点矩阵通常不能共享一份参考矩阵。

材料、载荷、支承（`end_corners`，即 `FullMBBBeamPoint3d`）、子结构划分、边界条件消元、CG 求解器与容差、热启动、过滤、OC 与停止条件两侧保持一致；预条件策略与参数也采用相同设置（具体方案待实现确定），实际实现差异在运行后注明。预条件子或粗层中的显式矩阵，其装配、存储与求解成本均计入统计。
