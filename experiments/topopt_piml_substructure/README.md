# PIML 子结构拓扑优化

## MBB 梁算例

采用 Huang2023 [1] 的三维 MBB 梁算例，在体积分数约束下最小化结构柔顺度。所有参数均为无量纲量。

### 模型参数

![MBB 梁的几何、载荷与支承](assets/Huang2023_Fig5.png)

梁的长、高、宽之比为 $6:1:1$，整体模型以细单元边长为长度单位（$h=1$），首档计算域为 $390\times65\times65$，使用整体模型，不利用对称性缩减计算域。顶面中心施加竖直向下的单位集中力 $F=1$。两端支承在侧视图中为一端铰支、另一端滚支。

| 材料参数 | 数值 |
|---|---|
| 实体材料杨氏模量 $E_0$ | $1$ |
| 弱材料杨氏模量 $E_{\min}$ | $10^{-7}$ |
| 泊松比 $\nu$ | $0.3$ |

长度约定依据原文图 8 的尺寸、网格数量及图 6 的柔顺度量级推断，并非原文明示。原尺度 $6\times1\times1$ 的第一档结果，在相同材料、密度和节点总载荷下，位移与柔顺度除以 65 可换算到当前尺度。接口系统柔顺度不直接等同于图中的 $C_{\mathrm{Fine}}$；比较论文数值前须对同一最终密度进行细网格分析。

### 有限元离散

| 参数 | 数值或设置 |
|---|---|
| 有限元 | 八节点六面体单元（Q1） |
| 位移插值次数 $p$ | $1$ |
| 数值积分 | 二阶高斯积分 |

### 子结构参数

| 项目 | 数值或设置 |
|---|---|
| 接口类型 | `full_trace`、`linear_corner` |
| 子结构细分参数 $m$ | $5$，即每个子结构包含 $5\times5\times5$ 个细单元 |
| 子结构网格规模 | $78\times13\times13$ |
| 全局细网格规模 | $390\times65\times65$ |
| 细单元边长 | $h=1$，作为复现长度约定 |

两种接口以迹矩阵 $\boldsymbol\Psi$ 表示边界位移：

| 接口类型 | 迹矩阵 $\boldsymbol\Psi$ | 局部接口未知量 $\boldsymbol q_j$ |
|---|---|---|
| `full_trace` | $\boldsymbol I$ | 完整边界位移 |
| `linear_corner` | $\boldsymbol L$ | 角点位移 |

其中，$\boldsymbol L$ 为由角点位移插值得到边界位移的矩阵，两种接口均满足 $\boldsymbol u_{jb}^h=\boldsymbol\Psi\boldsymbol q_j$。

| 参数 | 数值或设置 |
|---|---|
| 优化目标 | 最小化柔顺度 |
| 体积分数 | $0.12$ |
| 过滤半径 | $3$ 个细单元尺寸；对应实际长度 $r_{\min}=3h=3$ |
| 设计变量更新 | OC |
| 停止条件 | 连续最后 5 次迭代的目标函数相对变化小于 $0.0002$ |

### 补定参数（文献未给出）

| 参数 | 补定值 |
|---|---|
| 支承（待确认的建模选择） | 左端底边 $x=0,\ y=0$ 整条线：$u_x=u_y=u_z=0$；右端底边 $x=L_x,\ y=0$（首档 $L_x=390$） 整条线：$u_y=0$ |
| 集中力分配 | 顶面 $x=L_x/2$ 处（首档 $x=195$），$z$ 向距中心最近的 2 个节点各施加 $-1/2$ |
| 初始密度 | 均匀取 $0.12$ |
| 材料插值 | 修正 SIMP：$E_e=E_{\min}+\tilde\rho_e^{\,q}(E_0-E_{\min})$；设计密度 $\rho_e\in[0,1]$，物理密度为过滤后的 $\tilde\rho_e$ |
| SIMP 惩罚指数 $q$ | $3$（区别于位移插值次数 $p$） |
| 过滤 | 密度过滤：$\tilde\rho_e=\sum_i H_{ei}\rho_i/\sum_i H_{ei}$，$H_{ei}=\max(0,\ r_{\min}-d_{ei})$，$d_{ei}$ 为单元形心距离；物理密度取 $\tilde\rho$，灵敏度按链式法则过滤 |
| 体积约束 | $\sum_e v_e\tilde\rho_e/\sum_e v_e\leq0.12$，$v_e$ 为细单元体积；OC 体积判断使用物理密度，体积灵敏度对设计密度按链式法则计算 |
| OC 更新 | 移动限 $0.2$，阻尼指数 $0.5$；二分法求 Lagrange 乘子，初始区间 $[0,10^9]$，相对精度 $10^{-3}$ |
| 停止条件公式 | $r_k=\lvert c_k-c_{k-1}\rvert/c_k$，$r_{k-4},\dots,r_k$ 均小于 $2\times10^{-4}$ 时停止 |
| 最大迭代数 | $300$ |

### 对称性验收

论文展示对称结果，但未说明强制对称措施。整体优化时应记录物理密度关于厚度中面的镜像误差，并检查载荷、支承、过滤与求解残差；参考精确子结构入口的逐轮对称性记录。粗网格引起对称性破坏属于待验证假设，改变长度单位本身不会改变镜像关系。强制对称平均仅可作为单独的诊断对照，不作为默认复现算法。本目录尚无整体优化入口，因此此项为后续验收要求。

## PIML 子结构分析

### 方法选择

两条预测路线的局部计算方式为：

| 预测路线 | 预测对象 | 局部接口刚度 |
|---|---|---|
| `shape` | 内部位移映射 $\boldsymbol T_j$ 的独立条目，约束补全后得到 $\widehat{\boldsymbol T}_j$ | $\widehat{\boldsymbol K}_{r,j}=(\widehat{\boldsymbol N}_j^{(\Psi)})^{\mathrm T}\boldsymbol K_j^h\widehat{\boldsymbol N}_j^{(\Psi)}$ |
| `stiffness` | 接口刚度的独立条目 | 约束补全得到 $\widehat{\boldsymbol K}_{r,j}$ |

其中 $\widehat{\boldsymbol N}_j^{(\Psi)}=\begin{bmatrix}\boldsymbol\Psi\\\widehat{\boldsymbol T}_j\end{bmatrix}$。`stiffness` 路线仍需相同接口配置的形函数权重，用于细网格位移恢复及灵敏度计算。

### 网络输入

| 参数 | 数值或设置 |
|---|---|
| 网络输入 | 各细单元归一化杨氏模量 $\widehat E_e=E(\tilde\rho_e)/E_0$ |
| 输入维度 | $m^3$（三维） |
| 输入排序 | 与训练数据的细单元顺序一致 |

样本与权重须与上述模型、有限元离散及所选接口类型一致；不同接口分别生成样本并训练权重。材料采用三维各向同性线弹性。

### 均匀子结构判别

| 参数 | 数值或设置 |
|---|---|
| 均匀子结构判别阈值 $\rho_v$ | $10^{-4}$ |
| 判别对象 | 物理密度 $\tilde\rho_e$（实现选择） |
| 子结构平均密度 | $\rho_m^j=\frac{1}{125}\sum_{e\in\Omega_h^j}\tilde\rho_e$ |
| 判别条件 | $\lvert\max_{e\in\Omega_h^j}\tilde\rho_e-\rho_m^j\rvert<\rho_v$，$\rho_v=10^{-4}$ |
| 满足判据时的形函数 | 采用相同配置的实体材料子结构形函数 |
| 满足判据时的缩聚刚度 | $\boldsymbol K_{s,j}=\frac{E(\rho_m^j)}{E_0}\boldsymbol K_{s,j}^{\mathrm{solid}}$（修正 SIMP 下的实现选择，阈值内按均匀材料近似） |
| 未满足判据时 | 按所选路线预测形函数后构造刚度，或直接预测接口刚度 |

## 执行入口

`generate_samples.py` 为三维 MBB 局部样本生成入口，同时生成形函数与接口刚度的独立条目标签，不启动网络训练。默认配置与上面的样本参数一致；本目录尚无 PIML 拓扑优化执行入口。

`train_network.py` 为本目录的网络训练入口，仅使用已有样本，每次训练 `shape` 或 `stiffness` 一条路线。子结构分析走查参考 [PIML 子结构分析](../analysis_capability_piml_substructure/README.md)；这些入口尚不能替代完整 MBB 拓扑优化流程。上文配置为复现目标，尚未完成本算例的端到端数值验证。

在仓库根目录的 WSL 环境执行:

```bash
~/miniconda3/envs/ihpcm/bin/python experiments/topopt_piml_substructure/generate_samples.py
```

使用 `--n-sub NX NY NZ` 设置子结构网格，`--n-fine` 设置 $m$，`--fine-cell-size` 设置样本参考细单元边长（默认 1）。参考子结构各方向尺寸为 $m h_{\mathrm{sample}}$，整体域尺寸为各方向细单元数乘以 $h_{\mathrm{sample}}$；保持 MBB 长宽高比时，各方向网格数量之比须为 $6:1:1$。`--trace-kind` 选择接口类型，`--nu` 设置泊松比。`--n-train`、`--n-validation`、`--min-modulus` 和 `--sample-seed` 设置数据规模与采样；`--generation-batch-size` 与 `--outputs-root` 设置生成批量和产物根目录。空间维数固定为三维，有限元固定为 Q1、二阶高斯积分，数据精度固定为 `float64`。

生成写入 `--dataset-name` 指定的数据集目录，未指定时按接口、细分数、参考细单元边长、子结构网格、泊松比、采样下界、样本数量与随机种子生成配置名称，不使用时间戳。保存 `manifest.json`、六个 NPY 文件及 `generation_config.json`。后者记录参考细单元边长、全局细网格、子结构与整体域的派生尺寸、积分阶数与生成批量等运行配置。只有全部样本写完后，`manifest.json` 的 `complete` 才为 `true`；已有同配置完整数据集时拒绝重复生成；目标目录已存在时，无论是否完成都拒绝覆盖或续写。

验收时核对尺寸、采样下界、随机种子、训练与验证数量、两类标签维度及完成标记。当前 $h=1$ 数据集已完成生成，并通过文件完整性、全量有限性及配置核对。

### 样本生成运行设置

| 项目 | 设置 |
|---|---|
| 计算后端 | `numpy`（默认）、`pytorch` |
| 计算设备 | `cpu`（默认）、`cuda` 或 `cuda:N` |
| 样本生成批量 | $32$ |
| 样本保存目录 | `~/codespace/data/soptx/piml_substructure/independent_15_layer/samples/<dataset-name>/` |

当前使用 $h=1$ 的数据集 `mbb_linear_corner_m5_h1_nu0p3_emin1e-7_seed2026`，参考子结构尺寸为 $5\times5\times5$。自动名称包含 `_h1_`；显式指定 `--dataset-name` 时也应标明参考尺度。`nu0p3` 中的 `p` 代替小数点，表示泊松比 $0.3$，与位移插值次数或 SIMP 惩罚指数无关。目录名用于引用数据集，完整配置以 `manifest.json` 和 `generation_config.json` 为准。

生成批量控制内存与计算效率，保存目录指定输出位置。`--backend` 可选 `numpy` 或 `pytorch`，默认 `numpy`；`--device` 可选 `cpu`、`cuda` 或 `cuda:N`，默认 `cpu`。NumPy 仅支持 CPU，GPU 计算需选择 PyTorch；CUDA 不可用或设备编号越界时直接报错。

GPU 生成命令:

```bash

  --backend pytorch --device cuda:0 \
  --generation-batch-size 32
```

参考子结构使用 `--backend` 指定的后端在 CPU 上构建，独立条目编号由该参考结构确定并保存到 `manifest.json`；局部装配、批量内部消元、接口刚度计算、标签编码与补全检查在所选设备执行，最终标签转回 CPU 写盘。采样继续使用 NumPy 的独立随机子流，CPU/GPU 路线的同种子输入一致；标签可能存在浮点舍入差异。数据均为 `float64`，`generation_config.json` 记录实际后端与设备。后端和设备不改变样本的物理配置，但不同后端构建参考结构可能产生浮点或独立条目编号差异。数据查找严格核对参考结构元数据；本目录训练入口直接从保存的元数据恢复 codec。在线权重加载仍检查参考尺寸与独立条目契约，跨后端及跨尺度在线复用尚未验证。

~/miniconda3/envs/ihpcm/bin/python experiments/topopt_piml_substructure/generate_samples.py \

### 网络训练运行设置

训练命令必须显式指定 `--backend pytorch`，当前仅支持 PyTorch；`--device` 独立选择 CPU 或 CUDA。局部尺寸、网格、泊松比、接口空间与独立条目编号由样本 `manifest.json` 恢复，不重复指定样本生成参数，也不重新生成参考标签。通过 `IndependentPredictionDecoder.from_metadata()` 恢复补全器，使用保存的刚体基与 pivot 索引，无需创建有限元参考子结构。

在仓库根目录的 WSL 环境执行：

```bash
~/miniconda3/envs/ihpcm/bin/python experiments/topopt_piml_substructure/train_network.py \
  --samples-dir ~/codespace/data/soptx/piml_substructure/independent_15_layer/samples/mbb_linear_corner_m5_h1_nu0p3_emin1e-7_seed2026 \
  --route shape --num-networks 4 \
  --epochs 500 --batch-size 256 \
  --optimizer adam --lr 1e-3 --weight-decay 0 \
  --patience 40 --train-seed 2026 --backend pytorch --device cpu \
  --outputs-root ~/codespace/data/soptx/piml_substructure
```

GPU 训练改为 `--device cuda:0`。刚度网络训练使用 `--route stiffness --num-networks 1`，默认采用上表的 11 层配置；仅训练刚度网络，不同时训练形函数网络。自定义结构需同时指定 `--hidden-dims` 与等长的 `--activations`，后者支持 `tanh`、`elu` 和 `relu`。

### 相对重构刚度监督短程对照

`--stiffness-loss-weight` 默认 0, 保持原形函数矩阵 MSE. 对 shape 路线取正值时, 使用已有 `stiffness_targets` 精确标签增加监督:

$$
L=L_T+\lambda_K\frac{1}{N}\sum_{j=1}^{N}
\frac{\|\widehat K_j-K_j^{\mathrm{exact}}\|_F^2}
{\|K_j^{\mathrm{exact}}\|_F^2},\qquad
\widehat K_j=\widehat N_j^T K_{h,j}\widehat N_j.
$$

$L_T$ 为补全形函数矩阵 MSE. 刚度通过固定单元刚度与预测形函数的单元能量重构, 梯度保留到形函数网络. 计算相对损失时, 真实模量与精确刚度同时除以样本最大模量以改善数值尺度, 不裁剪材料对比度. 该监督属于实验扩展, 不使用刚度预测网络作为教师, 不等同于论文的两网络后期一致性损失. 原数据和精确标签无需重新生成.

`--loss-chunk-size 32` 将优化器 batch 划为计算块. 各块按其样本数占 batch 的比例累积梯度, 整个 batch 完成后只更新一次, 末块也正确加权. 默认未指定时使用完整 batch. 权重, run_config 与训练历史保存损失设置, 总损失以及矩阵 MSE / 相对刚度损失分量. 最佳轮由验证总监督损失选择; 不同 $\lambda_K$ 的总损失不能直接比较, 对照应使用共同的矩阵及刚度误差指标.

配对试验从 `mbb_mixed_per_sample_max_extended100_trainseed2033/shape_best.pt` 初始化, 两组各 5 轮, 相同混合数据, seed 2034, Adam, 学习率 $10^{-4}$, batch 256, 计算块 32. 唯一目标差异为 $\lambda_K=0$ 或 1. 默认输出目录为正权重增加 `_kweight<值>` 后缀, 拒绝覆盖已有目录. 镜像平均仍仅用于临时验证, 不写入训练权重或生产预测契约.

配对短程训练已完成. 使用临时镜像平均时, 空间相关验证样本的重构刚度平均 / 95 分位 / 最大误差, MSE 基准组为 1.17% / 3.47% / 10.07%, 刚度监督组为 0.79% / 2.19% / 8.22%. 原随机材料回归刚度平均误差从基准组 0.73% 降至 0.65%. 刚度监督组原始形函数验证 MSE 为约 $1.1765\times10^{-4}$, 略高于基准组约 $1.1390\times10^{-4}$; 该损失改善的是物理刚度精度, 不能宣称所有形函数指标都改善.

刚度监督组配合临时镜像平均, 在精确优化第 10 步固定结构上的柔顺度 / 位移误差为 0.69% / 0.77%, 完整梯度方向有限差分检查通过. 空间相关材料的最大刚度误差仍超过 5% 实验门槛, 所以尚未通过正式 MBB 复现验收. 本轮未使用独立测试集选模, 未运行新的优化迭代或论文规模算例. 比较报告及可复现验证脚本位于 `~/codespace/data/soptx/piml_substructure/independent_15_layer/mixed_validation/mbb_mixed_kloss_short5_trainseed2034/`.

### 固定权重的训练家族与梯度诊断

针对 20 轮补样最佳权重, 扫描全部 22000 个训练样本, 分别计算原始预测与临时镜像平均的形函数及重构刚度误差. 同时按全训练集均值累计原始预测的形函数 MSE 梯度及相对刚度平方损失梯度. 从训练误差独立排序选择最高的 10 个空间相关家族及镜像, 共 20 个样本, 并与随机空间相关训练样本及 2000 个补样比较. 未执行优化器更新, 模型参数和 checkpoint SHA256 在诊断前后保持不变.

训练集空间相关样本经临时镜像平均后的刚度平均 / 95 分位 / 最大误差为 0.7377% / 1.8804% / 5.8688%, 有 3 个家族共 6 个训练样本超过 5%. 满足补样密度范围的训练样本已有 4542 个, 共 2271 个家族. 剩余验证超限家族在训练集中存在归一化模量 RMS 距离约 0.0401 的近邻, 该近邻来自补样, 刚度误差约 1.68%. 该距离只是材料场相似性指标, 不能证明局部几何模式完全覆盖; 验证输入仅用于诊断比较, 不参与训练选样.

原始训练目标在全训练集上的两种梯度余弦约为 0.404, 难例组约为 -0.0018, 临时镜像平均难例组约为 0.0362. 没有发现明显的形函数 / 刚度梯度对抗. 难例组刚度梯度范数约为形函数梯度的 12--15 倍. 全训练集联合负梯度对难例刚度损失的方向导数为负, 即一阶意义下有利于降低该误差. 用函数式临时参数验证此方向, 有限差分相对误差约为 3.03e-9. 这不是对 Adam 后续收敛或网络容量的证明.

对这 20 个训练难例, 精确形函数重构刚度与保存标签的最大相对误差约为 1.22e-14. 预测刚度误差满足形函数误差的二次能量恒等式, 相对残差约为 1.25e-14. 未发现精确标签相互不一致导致的冲突.

读取保存的 Adam 动量, 对同一难例批量计算一次假想更新方向, 不更新模型. 原始预测在完整假想步长下的刚度平方损失从约 0.002685 增至 0.06089, 而步长取 10% 时降至约 0.002377, 形函数 MSE 也下降. 镜像平均诊断呈同样趋势. 这是特殊难例批量的局部步长探针, 不是实际全数据随机训练的下一步, 不能据此认定原训练发生了同样的过冲.

现有证据表明训练本身仍存在难例拟合不足, 不支持仅归因为验证集缺少覆盖或两种损失冲突; 网络容量是否足够尚未通过拟合实验确认. 下一步建议保持网络及精确标签, 从训练集独立选择的难例进行 100 步小学习率拟合诊断, 学习率 1e-5, 保留保存的 Adam 状态, 再检查其他训练材料的回归误差. 该试验用于检查局部拟合能力, 不把验证超限样本加入训练, 不将诊断权重直接认定为正式复现权重.

诊断脚本及完整结果位于 `mixed_validation/mbb_mixed_sparse_extended20_gradient_diagnostic/`, 包括 `diagnose_gradients.py`, `check_energy_and_adam.py`, `training_errors.npz`, `energy_and_adam.json` 和 `summary.json`. 未读取独立测试集, 未修改训练数据, 未运行新的优化或论文规模算例. 目前权重仍未通过此前的正式复现前置验收.

两组误差接近且 fit 本身未拟合充分, 因此本轮没有证据将问题主要归因于未见家族泛化; 同样不能直接判定为网络容量不足. 当前结论为: 更新失稳已在本轮预算内缓解, 精度问题仍未解决, 新权重不能作为正式 MBB 复现的可靠权重. 未继续执行结构, 灵敏度或收敛优化验收. 后续应先在 fit 内诊断拟合瓶颈并预定训练方案和预算, 不将 probe 加入训练或反复用于挑选权重.

源权重, 原 manifest 与输入摘要保持不变, fit 与 probe 家族无重叠, 恢复的 Adam 步数与 RNG 状态已核验. 最终权重重新加载后参数摘要一致, 误差数组全部有限, 评估没有更新模型. 原权重与公共训练默认设置未替换.
