# 传统有限元 EA 与 FA 拓扑优化结果对照

硬件：AMD Ryzen 9 9950X（16 核 32 线程），运行内存 45 GiB；NVIDIA GeForce RTX 5070 Ti，显存 16 GB。

软件：`ihpcm` 环境，Python 3.12.13，NumPy 2.5.3，SciPy 1.18.1，PyTorch 2.11.0（CUDA 12.8）。

## 1. 研究对象

对照 `experiments/topopt_simp_fem/run_ea.py` 与 `experiments/topopt_simp_fem/run_fa.py` 在 CPU 上对 Huang2023 三维 MBB 梁首档（$390\times65\times65$，$1\,647\,750$ 个单元，$5\,109\,588$ 个自由度）的完整优化结果。两个脚本求解同一离散系统，唯一的差别是刚度算子的装配层级：

| | EA | FA |
|---|---|---|
| 刚度算子 | 一份参考单元刚度 $K^0$ 乘逐单元系数，不形成全局矩阵 | 全局 CSR 稀疏矩阵，由 $K^0$ 乘系数装配 |

材料、载荷、支承（`end_corners`）、边界条件消元、MGCG 求解器与容差、过滤、OC 与停止条件两侧完全一致，见各自 README。

## 2. 结果一致性

两侧优化轨迹逐轮一致，终止于同一轮，最终设计相同。


| 指标             | EA                          | FA                  |
| -------------- | --------------------------- | ------------------- |
| 终止             | 收敛，68 轮                     | 收敛，68 轮             |
| 最终柔顺度 $C$      | $9.4209265487$              | $9.4209265484$      |
| 最终体积分数         | $0.119999$                  | $0.119999$          |
| 每轮 CG 步数       | 首轮 13，最大 26，均值 19.7，总计 1337 | 逐轮相同                |
| 末轮 CG 相对残差     | $9.49\times10^{-7}$         | $9.49\times10^{-7}$ |
| 物理密度 $z$ 向不对称量 | $2.7\times10^{-15}$         | $2.7\times10^{-15}$ |
| 设计密度 $z$ 向不对称量 | $0$                         | $0$                 |


两侧差异：


| 量              | 最大差                   |
| -------------- | --------------------- |
| 逐轮柔顺度相对差       | $2.4\times10^{-10}$   |
| 最终物理密度         | $3.2\times10^{-8}$    |
| 最终设计密度         | $6.5\times10^{-7}$    |
| 最终位移相对 $L^2$ 差 | $1.7\times10^{-10}$   |
| 阈值 $0.5$ 二值化拓扑 | 逐单元相同，实体单元 $196\,273$ 个 |


差异处于 CG 容差 $10^{-6}$ 与浮点求和顺序的量级，EA 与 FA 可视为同一离散算子的两种实现。

## 3. 计算成本

### 3.1 耗时

| 阶段 | EA | FA | 说明 |
|---|---|---|---|
| 准备：网格 | 8.3 | 9.0 | 生成节点、单元与自由度编号 |
| 准备：分析器 | 0.7 | 0.6 | 积分参考单元刚度 $K^0$ |
| 准备：过滤矩阵 | 7.7 | 9.0 | 构造过滤矩阵 $H$ |
| 准备：目标与约束 | 1.0 | 1.0 | 体积约束梯度及其过滤 |
| 迭代：过滤 | 0.22 | 0.22 | 设计密度过滤为物理密度 |
| 迭代：装配 | 0.07 | 4.92 | EA 更新单元系数，FA 按系数装配 CSR 值数组；FA 首轮建立 CSR 骨架与装配缓存需 23 s，已计入均值 |
| 迭代：边界条件 | 1.44 | 2.82 | EA 包装消元算子，FA 改写 CSR 值；EA 首轮建立消元槽位需 16 s，已计入均值 |
| 迭代：求解 | 40.68 | 21.03 | MGCG，上一轮位移热启动 |
| 迭代：灵敏度 | 1.87 | 1.83 | 柔顺度、单元级能量与灵敏度过滤 |
| 迭代：输出 | 1.71 | 1.78 | 写出本轮 VTU 并更新 PVD |
| 迭代：OC | 0.50 | 0.54 | 更新设计变量 |

整个流程：

| 项目 | EA | FA | 说明 |
|---|---|---|---|
| 每轮合计 / s | 46.5 | 33.1 | 迭代各阶段之和，68 轮均值 |
