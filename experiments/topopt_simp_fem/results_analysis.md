# 传统有限元 EA 与 FA 拓扑优化结果对照

硬件：AMD Ryzen 9 9950X（16 核 32 线程），运行内存 45 GiB（WSL2 上限 48 GB）；NVIDIA GeForce RTX 5070 Ti，显存 16 GB。

软件：Ubuntu 24.04（WSL2），`ihpcm` 环境，Python 3.12.13；NumPy 2.5.3（conda-forge，链接 BLIS 2.0 与 netlib LAPACK），SciPy 1.18.1（内置 scipy-openblas 0.3.31），PyTorch 2.11.0（CUDA 12.8）；PyMUMPS 0.4.0，链接 MUMPS 5.8.2（BLIS 2.0、netlib LAPACK、Open MPI 5.0.11、ScaLAPACK 2.2.0）；pyevtk 1.7.0。

## 1. 研究对象

对照 `topopt_simp_fem/run_ea.py` 与 `topopt_simp_fem/run_fa.py` 在 CPU 上对 Huang2023 三维 MBB 梁（$390\times65\times65$，$1647750$ 个单元，$5109588$ 个自由度）的完整优化结果。

|      | EA                            | FA                        |
| ---- | ----------------------------- | ------------------------- |
| 刚度算子 | 一份参考单元刚度 $K^0$ 乘逐单元系数，不形成全局矩阵 | 全局 CSR 稀疏矩阵，由 $K^0$ 乘系数装配 |


材料、载荷、支承（`end_corners`）、边界条件消元、MGCG 求解器与容差、过滤、OC 与停止条件两侧完全一致。

## 2. 结果一致性

两侧优化轨迹逐轮一致，终止于同一轮，最终设计相同。

| 指标             | EA                          | FA                  |
| -------------- | --------------------------- | ------------------- |
| 终止             | 收敛，68 轮                     | 收敛，68 轮             |
| 最终柔顺度 $C$      | $9.4209265487$              | $9.4209265484$      |
| 最终体积分数         | $0.119999$                  | $0.119999$          |
| 每轮 CG 步数       | 首轮 13，最大 26，均值 19.7，总计 1337 | 逐轮相同                |
| 末轮 CG 相对残差     | $9.49\times10^{-7}$         | $9.49\times10^{-7}$ |
| 物理密度 $z$ 向不对称量 | $2.7\times10^{-15}$         | $2.7\times10^{-15}$ |
| 设计密度 $z$ 向不对称量 | $0$                         | $0$                 |


数据来源：`results/ea_hex_390x65x65_cg/`、`results/fa_hex_390x65x65_cg/` 的 `summary.json` 与 `history.json`。

两侧差异：


| 量              | 最大差                   |
| -------------- | --------------------- |
| 逐轮柔顺度相对差       | $2.4\times10^{-10}$   |
| 最终物理密度         | $3.2\times10^{-8}$    |
| 最终设计密度         | $6.5\times10^{-7}$    |
| 最终位移相对 $L^2$ 差 | $1.7\times10^{-10}$   |

数据来源：柔顺度相对差来自两侧 `history.json`，其余来自 `results/final_fields.json` 。

## 3. 计算成本



### 3.1 耗时


| 阶段       | EA    | FA    | 说明                                                         |
| -------- | ----- | ----- | ---------------------------------------------------------- |
| 准备：网格    | 8.3   | 9.0   | 生成节点与单元，急切构造面、边及其关联数组                                      |
| 准备：分析器   | 0.7   | 0.6   | 构造材料、插值方案、标量与张量函数空间及积分子；$K^0$ 不在此积分，首次用到时（首轮装配）才计算并缓存 |
| 准备：过滤矩阵  | 7.7   | 8.9   | 构造过滤矩阵 $H$                                                 |
| 准备：目标与约束 | 1.0   | 1.0   | 体积约束梯度及其过滤                                                 |
| 迭代：过滤    | 0.22  | 0.22  | 设计密度过滤为物理密度                                                |
| 迭代：装配    | 0.07  | 4.92  | 每轮不计算单刚：EA 只更新单元系数 $s_e$，FA 把缓存的 $K^0$ 按 $s_e$ 缩放后散加进 CSR 值数组；首轮另含 $K^0$ 的首次积分（1 个代表单元加 2 个抽查单元，可忽略），FA 首轮建立 CSR 骨架与装配缓存需 23 s，已计入均值 |
| 迭代：边界条件  | 1.44  | 2.82  | 两侧每轮重建右端项并施加约束，FA 另复制并改写 CSR 值数组；EA 首轮 16 s，FA 首轮 21 s，已计入均值，推断主要来自两侧共用的 Dirichlet 掩码与基准向量的首次计算，FA 另含建立消元槽位 |
| 迭代：求解    | 40.68 | 21.03 | MGCG，上一轮位移热启动                                              |
| 迭代：灵敏度   | 1.87  | 1.83  | 柔顺度、单元级能量与灵敏度过滤                                            |
| 迭代：输出    | 1.71  | 1.78  | 写出本轮 VTU 并更新 PVD                                           |
| 迭代：OC    | 0.50  | 0.54  | 更新设计变量                                                     |


来源：准备各行取 `summary.json` 的 `setup_stages.<阶段>.seconds`；迭代各行取 `history.json` 各轮 `stages.<阶段>.seconds` 的算术均值，共 68 轮且含首轮，OC 为 67 轮（末轮收敛即停，不再更新）；首轮耗时取 `history[0]`。

整个流程：


| 项目        | EA   | FA   | 说明             |
| --------- | ---- | ---- | -------------- |
| 每轮合计 / s  | 46.5 | 33.1 | 迭代各阶段之和，68 轮均值 |
| 总耗时 / min | 53.0 | 37.9 | 准备加 68 轮迭代     |


来源：每轮合计为上表迭代各行均值之和；总耗时为 `setup_stages` 四项与 `history.json` 全部轮次全部阶段的 `seconds` 之和。`summary.json` 的 `total_seconds` 只计迭代循环（EA 52.7 min，FA 37.6 min），口径与本表不同。
