## 算例设置

- 问题：FullMBBBeam2d，domain (0, 12) x (0, 2)，E = 1.0，nu = 0.3，P = -1.0
- 子结构划分：12 x 2（共 24 个），细网格 5 x 5，每子结构接口自由度 n_b = 40
- 接口自由度总数 574，自由接口自由度 n_free = 571
- 密度场：逐细单元变化，取值区间 (0.3, 1.0)（与 `piml_substructure_elasticity/_common.py` 的 DENSITY_RANGE 一致）
- 缩聚：精确 Schur 补（`FEAStaticCondensation`）
- 随机种子 2026，随机向量 20 组（NumPy 生成后转后端，两后端输入逐位相同）
- CG：无预条件，rtol 1e-10，atol 0

## 结论

1. **算子级恒等成立**：七项判据在阈值 1e-13 下实测全部落在 1e-18 ~ 1e-15 量级，即「差异只来自浮点求和次序」的预期水平；`diagonal()` 闭式与 `apply_full` 反力路径在 numpy 下逐位一致。按判据的反向诊断逻辑，编号映射与散加逻辑无索引错误，`InterfaceOperator` 与显式装配是同一个和的两种求值次序。
2. **求解级可替换成立**：两条 CG 的迭代数至多差 1（numpy 差 1 为停机边界舍入，pytorch 完全相同），解相互一致到 1e-13 量级，远优于 1e-8 阈值——Krylov 轨迹实际重合。显式接口矩阵可从求解流程整个拿掉，`fealpy.solver.cg` 直接吃算子，行为与显式矩阵一致。
3. 两后端在同一随机输入下的判据数值同量级、结论一致，实现是后端无关的。
4. 本页只含正确性结论，不含性能结论；两后端迭代数差 2（343/342 vs 341/341）来自 MatVec 浮点次序差异对停机边界的扰动，属正常。
