## 诊断分析

**speedup 范围**: 0.46× – 2.43×

### 1. GPU 收益拐点

拐点出现在 **128×128** (DOFs ≈ 33282)，此后 GPU 开始有正向收益。

### 2. 装配阶段

GPU 装配时间随规模增长**几乎持平**（kernel 启动开销主导），CPU 装配随 DOF 线性增长。最大规模下 GPU 装配 9.1× 快于 CPU。

### 3. 求解阶段

CG 求解是 GPU 的主要收益来源。最大规模下 GPU 求解 1.9× 快于 CPU。

### 4. 边界条件处理 (BC)

BC 阶段 GPU 一直慢于 CPU——此阶段涉及稀疏索引和条件赋值，GPU 天生不擅长。但其绝对时间短（≤ 0.02s GPU vs ≤ 0.11s CPU），随 DOF 增大占比快速下降，不构成瓶颈。

### 5. 总耗时与实用建议

三档网格 CPU 总耗时 1.9s，GPU 收益的拐点约在 **3 万 DOF** 附近，**13 万 DOF 时达到 2.4× speedup**。对 SOPTX 的典型拓扑优化迭代（每步一次求解），中等规模以上使用 GPU 后端可有效缩短单步耗时。
